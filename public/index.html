Dockerless Process Trees

Android kernel namespaces strictly prohibit Docker without rooting. PhonixPaaS bypasses container bloat entirely, spawning isolated, supervised OS process trees. Leaving 95%+ of RAM available for PostgreSQL, Redis, Node, and Python.

Zero-Config Deployment

Install on Android in 60 Seconds

No root required. Compatible with any phone running Android 7.0+ and Termux.

termux@android: ~/phonix-paas
# 1. Update Termux packages & install git + nodejs
$ pkg update -y && pkg install -y git nodejs
# 2. Clone PhonixPaaS & run the native installer
$ git clone https://github.com/your-username/phonix-paas.git ~/phonix-paas
$ cd ~/phonix-paas && bash scripts/install.sh
# 3. Open dashboard from any laptop or browser on your Wi-Fi:
